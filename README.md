# Employee Attendance Dashboard – Power BI

## Project Overview

This project presents an interactive Employee Attendance Dashboard developed using Microsoft Power BI for HR and MIS reporting.

The dashboard provides a consolidated view of employee attendance, absenteeism, leave, work-from-home trends and department-wise attendance performance.

The objective was to transform raw employee attendance data into an easy-to-understand management dashboard that can support HR teams in monitoring workforce attendance and identifying attendance-related trends.

## Tools & Technologies

- Microsoft Power BI
- DAX
- Power Query
- Microsoft Excel
- Data Cleaning
- Data Modeling
- Data Visualization

## Dashboard Features

### Attendance Overview

The dashboard provides:

- Total Employees
- Overall Attendance %
- Present Days
- Absent Days
- Leave Days
- Work From Home Days
- Daily Attendance Trend
- Attendance Status Distribution
- Department-wise Attendance
- Location-wise Attendance
- Department-level attendance summary

### Employee Analysis

The dashboard also provides employee-level attendance information including:

- Employee ID
- Employee Name
- Department
- Location
- Present Days
- Absent Days
- Leave Days
- WFH Days
- Half Days
- Attendance %
- Average Working Hours

## Key Power BI Concepts Used

- Data cleaning using Power Query
- Data modeling
- Relationships between employee and attendance tables
- DAX measures
- KPI cards
- Slicers and filters
- Conditional formatting
- Interactive charts
- Department and location analysis

## Data Model

The project uses employee master data, attendance records and calendar information to create a structured reporting model.

The Employee ID is used to connect employee information with attendance records, while the Calendar table is used for date-based analysis.

## Business Questions Answered

The dashboard helps answer questions such as:

- What is the overall employee attendance rate?
- Which departments have the highest and lowest attendance?
- Which locations have lower attendance?
- How many employees were absent or on leave?
- What is the daily attendance trend?
- How many employees are working from home?
- Which employees have relatively low attendance?
